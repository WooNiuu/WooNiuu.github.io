药物临床试验的生物统计学指导原则（CDE）

2026-03-14
阅读时长: 5 分钟

要点

指南（征求意见稿）的主要修订：

  • 扩大适用范围，增加了中药和天然药
  • 增加了临床研发规划的内容
  • 增加了适应性设计和富集设计的相关内容
  • 补充了有关数据监察的内容

指导原则中有关研究设计的要点：

  • 探索性和验证性试验
  • 观察指标的选择
  • 偏倚的控制
  • 试验设计的类型
  • 比较的类型
  • 样本含量的确定

临床试验设计的统计学考虑

研究的目的与假设

  • 明确所要解决的医学问题，确定研究目的 如：验证XX药物治疗XX疾病的有效性和安全性

  • 采用准确的统计学语言描述待解决的医学问题 和XX比，在XX指标上，体现XX药物优于/非劣效于/等效于XX的疗效

  • 提出统计学假设(Hypothesis)，确定相关的参数 确定相关的参数(期望的效应大小，非劣效界值等)，提出统计零假设($H_0$)和备则假设($H_1$)

评价指标

  • 评价指标(Endpoint)的确定
    • 临床意义
    • 可靠性
    • 可操作性
  • 评价指标的统计学特性
    • 分类(Category)/连续(Continuous)/事件时间(Time to Event)
    • 可转换性(如连续指标 → 分类指标)
  • 主要疗效指标(Primary Endpoint).
    • 疗效评价的主要依据（可能的金标准），可靠性、操作性
    • 替代指标(Surrogate Endpoint)
    • 多个主要疗效指标(Co-Primary Endpoint)

对照类型

  • 同期空白对照
  • 同期安慰剂对照
  • 同期剂量-反应对照
  • 同期阳性对照
  • 历史对照

统计学比较类型

此处以两组的平行组设计试验为倒，E代表试验组，C代表对照组

  • 优效性试验，用以证明E优于C

  1. 优效性试脸的应用场合 任何需要证明E此C好的临床研究，比如采用空白对照，安慰剂对照、剂量反应对照以及某些阳性对照时

  2. 统计学优效与临床优效 一般情况下，一个可接受的有临床意义的最小疗效差别需预先加以考虑

  3. 示例：一项三期临床注册试验 一项随机、双盲、平行组设计临床试验，用以评价妥泰与安慰剂对比在预防性治疗偏头痛方面的疗效和安全性 主要疗效指标：偏头痛月平均发生率相对于基线的变化； 统计学方法：采用协方差分析方法(ANCOVA)估计组间最小二乘均数的差值及其95%可信区间； 如果组间最小二乘均数差值的95%可信区间下限大于0 (相当于组间差异具有统计学意义，P < 0.05),则认为妥泰治疗偏头痛的有效性；

  4. 有关优效性试验的注意事项

    • 统计学上的显著性不总是代表有临床意义的差别，研究结果的临床意义需依据医学实践从研究结果的点估计值上来判断
    • 优效性试验结果的差别不显著( P > 0.05 )，绝不代表两处理组的疗效相等
    • 如果有理由相信两组疗效相等（相当），需采用等效性试验来加以验证
  • 等效性试验，用以证明E等效于C

  1. 等效性试验的应用场合 任何需要证明E和C的疗效相等/相当的情况下，此时一般采用阳性对照（标准疗法）

  2. 临床等效的定义 对于等效性试验，需对临床等效进行事先定义 临床等效的可做如下表述：两组疗效的差别不超过临床上认可的最大可接受范围$\delta$，=>确定临床等效区间

  3. 示例：一项仿制药的临床注册试验 一项随机、开放、多中心、平行组设计研究，用以验证药物X（一种抗血检治疗的仿制药）和药物Y（抗血检治疗的原研药）在治疗急性心急梗死患者方面的临床等效性 主要疗效指标：治疗开始后30天之内的病死率； 统计学方法：将计算治疗后30天之内两组病死率差值的双侧95%可信区间，如果95%可信区间完全落入-5% ~ 5%，则认为 X 和 Y 临床等效；

  4. 有关等效性试验的其它事项

    • 多数情况下等效性试验为生物等效性(BE)，用以验证仿制药和原研药在 PK 指标方面的一致性
    • 在生物等效性试验中，一般采用 90% 的可信区间
  • 非劣效性试验，用以证明E不比C差

  1. 非劣效性试验的应用场合 任何需要证朋E跟C疗效相当或优于C(即 E 不比 C 差)的情况下，此时选用阳性对照

  2. 非劣效界值(NI，Non-inferiority Margin) 非劣效界值(NI)是非劣效试脸设计的重要参数之一 NI的确定可参考相应的指南

  3. 示例：一项三期临床注册试验 一项随机、开放，平行组设计临床试验，用以评价帕利哌酮在治疗精神分裂症方面和利培酮长效针剂相此的非劣效性 主要疗效指标：治疗后PANSS评分相对于基线的变化； 统计学方法：将计算PANSS评分相对于基线变化的组间均数差值的 95% 可信区间，如果帕利哌酮-利培酮长效针剂的差值 95% 可信区间下限大于-5.5，则认为帕利哌酮非劣效于利培酮长效针剂；

  4. 非劣效性试验的具体应用场景

    • 安慰剂对照试脸不符合伦理的情况下
    • E在主要疗效指标上不比C好，但在次要疗效指标上明显优于 C
    • E在主要疗效指标上不比C好，但安全性更好
    • E在主要疗效指标上不比C好，但更便宜或方便使用
    • 在临床试脸的环境中，E在主要疗效指标上不比C好，但在实际医疗环境中，由于更好的用药依从性而能获得更好的疗效

  5. 非劣效界值的确定

    • 临床推导：根据临床共识直接确定
    • 统计学推导：一般根据阳性对照药物与安慰剂相比较的效应的既有证据来确定
      • 构建(C-P)的区间估计（C-阳性对照，P安慰剂），区间下限作为阳性对服的疗效估计$M$；
      • 取$ M_1 < M $，视为可接受的最大非劣效界值；
      • 如取$M_1$为NI，拒绝H0则可间接推断出试验药优于安慰剂；
      • 如取$M_2=(1-f)M_1，0 < f <1$，为NI，拒绝H0则可推论出试验药非劣效于阳性对照，且至少保持了阳性对照疗效M的f倍；

  6. 有关非劣效试验的注意事项

    • 非劣效的结论的含义
      • 试险药的疗效优于安慰剂（间接推论试脸药物的有效性）;
      • 试验药的疗效若是比阳性对照药物的疗效差，其差值也是在临床可接受的范围内;
    • 阳性对照有效性的既有证据
      • 阳性对照的效应来源于文献报道的有良好试验设计(RCT)的试验结果;
      • 阳性对照药物效应的稳定性;
    • 评价指标的选择
      • 疗效的一致性与效应大小的度量方法有关;
      • 率比RR 或 风险比HR 较 率差 相对稳定;
    • 非劣效临床试验中的优效性判断
      • 如果仅有一个主要疗效指标、且受试药为单剂量时，允许在非劣效检验结论成立后进行优效性结论判断
